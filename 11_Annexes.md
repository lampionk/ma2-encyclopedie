# Annexes – Outils divers

### Plugin : ZZZ assignation macro layout test

- Permet d’assigner automatiquement une série de macros à un layout selon des coordonnées (x,y).
- Structure : `start_macro`, `end_macro`, `layout_id`, `spacing_x`, etc.
- Commande clé : `Assign Macro x At Layout y /x=Z /y=T /nc`
- Pratique pour organisation visuelle des macros par fonction.
