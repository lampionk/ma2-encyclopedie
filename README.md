# Encyclopédie grandMA2 – Scripts & Bonnes pratiques

Ce dépôt contient une **documentation exhaustive** sur le développement de plugins Lua et la programmation dans **grandMA2**, adaptée pour le projet Disco, mais réutilisable dans tout show MA2.

## 📚 Contenu

Chaque fichier `.md` correspond à une section indépendante de l'encyclopédie.

## 🔍 Table des matières rapide

Voir [00_Menu.md](./00_Menu.md)

## 🛠️ Objectif

- Centraliser les connaissances MA2
- Documenter les scripts existants
- Créer une base pédagogique pour apprendre ou enseigner MA2+Lua
- Maintenir un standard clair pour les macros, presets, effects, layouts
