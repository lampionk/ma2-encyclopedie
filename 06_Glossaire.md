# Glossaire MA2

| Terme | Définition |
|------|------------|
| Cue | Une étape d'une séquence (state mémoire) |
| Sequence | Liste ordonnée de Cues jouée via un Executor |
| Executor | Fader ou bouton contrôlant un élément (sequence, macro, effect...) |
| Preset | Mémorisation de valeurs d'attributs par catégorie (Dim, Pos, Col...) |
| Effect | Générateur automatique de variation (sinus, saw, step...) |
| World | Sous-univers limitant les fixtures visibles/éditables |
| Group | Sélection de fixtures enregistrée |
| Macro | Suite de commandes exécutables |
| Appearance | Apparence graphique assignée (icône/couleur) |
| Matriçks | Système de distribution spatiale (blocks, wings, interleave...) |
| Track | Mode de suivi des valeurs entre cues (On/Off) |
